실제 사용되는 레이아웃 시스템입니다.
- 사이드바: 240px 고정 너비, 접기/펼치기 기능
- 유틸리티 헤더: 48px 고정 높이 (브레드크럼 + 알림 + 사용자 정보)
- 페이지 헤더: 72px 고정 높이 (페이지 제목 + 도움말 텍스트)

- .layout-v3-sidebar-logo: 32x32px, Crimson 배경, 흰색 텍스트
- .layout-v3-sidebar-toggle: 28px 원형, Crimson 배경 (접기 버튼)

사이드바 메뉴 구조
<nav class="layout-v3-sidebar-nav"> <!-- 1depth 메뉴 --> <a class="layout-v3-nav-item active"> <svg>...</svg> <span>대시보드</span> </a> <!-- 2depth 메뉴 (접기/펼치기) --> <div> <button onclick="toggleSubmenu('id')">논문 안내</button> <div id="submenu"> <a class="sidebar-sublink">공지사항</a> <a class="sidebar-sublink">자료실</a> </div> </div> </nav>

- 1depth: .layout-v3-nav-item (아이콘 + 텍스트)
- 2depth: .sidebar-sublink (텍스트만, 좌측 들여쓰기)
- Active 상태: Crimson 배경 tint + Crimson 텍스트 색상

사이드바 하단 (로그아웃)
<div class="layout-v3-sidebar-footer"> <button class="layout-v3-sidebar-logout"> <svg>...</svg> 로그아웃 </button> </div>

Utility Header 컴포넌트 (48px)

유틸리티 헤더 구조
<header class="layout-v3-utility-header"> <!-- 좌측: 햄버거 메뉴 + 브레드크럼 --> <div class="layout-v3-utility-left"> <button class="layout-v3-sidebar-open-btn">...</button> <div class="layout-v3-breadcrumb"> <a>홈</a> <span class="layout-v3-breadcrumb-separator">></span> <span class="layout-v3-breadcrumb-current">대시보드</span> </div> </div> <!-- 우측: 알림 + 사용자 정보 --> <div class="layout-v3-utility-right"> <button class="layout-v3-utility-icon-btn"> <svg>알림 아이콘</svg> </button> <div class="layout-v3-user-info"> <span class="layout-v3-user-role">지도교수</span> <span class="layout-v3-user-divider">│</span> <span class="layout-v3-user-name">김교수</span> </div> </div> </header>

- 햄버거 메뉴: 사이드바 접힘 상태에서만 표시
- 브레드크럼: 현재 페이지 위치 표시 (홈 > 대시보드)
- 알림 버튼: 32x32px
- 사용자 정보: 역할 + 이름 + Avatar (선택)

Page Header 컴포넌트 (72px)

페이지 타이틀 + 도움말 텍스트
<div class="layout-v3-page-header"> <div class="layout-v3-page-header-left"> <h1 class="layout-v3-page-title">대시보드</h1> <p class="layout-v3-page-help-text">논문 지도 현황을 한눈에 확인하세요</p> </div> </div>

- .layout-v3-page-title: 24px, Bold (700), 제목 텍스트
- .layout-v3-page-help-text: 14px, Secondary 색상, 도움말 텍스트
- 두 요소는 하단 정렬 (align-items: flex-end), 16px gap

Search Container 컴포넌트

검색 영역 구조
<div class="search-container"> <div class="search-grid"> <div class="search-field"> <label class="search-label">학년도</label> <select class="search-select">...</select> </div> <div class="search-field"> <label class="search-label">학번</label> <input class="search-input" placeholder="학번 입력"> </div> </div> <div class="search-buttons"> <button class="btn btn-secondary">초기화</button> <button class="btn btn-primary">검색</button> </div> </div>

- .search-container: 흰색 배경, 24px 패딩, border-radius 4px

- .search-field: 라벨 + 입력 필드 세로 배치
- .search-buttons: 중앙 정렬, 12px gap, 상단 마진 16px

모바일 반응형

사이드바 오버레이 (모바일용)

- 모바일에서 사이드바 열림 시 배경 오버레이 (반투명 검정)
- z-index: 350 (사이드바보다 낮음)
- .active 클래스로 표시/숨김 제어

사이드바 모바일 제어
<!-- 기본 상태: 숨김 (translateX(-100%)) --> <aside class="layout-v3-sidebar">...</aside> <!-- 모바일 열림: .mobile-open 클래스 추가 --> <aside class="layout-v3-sidebar mobile-open">...</aside>

- 768px 이하에서 사이드바 기본 숨김
- 햄버거 메뉴 클릭 시 .mobile-open 클래스 추가/제거
- 오버레이 클릭 시 사이드바 닫힘

v5 업데이트 요약

신규 추가된 컴포넌트

  • Layout System v3: 전체 3-Part 레이아웃 구조 (Sidebar + Utility Header + Page Header)
  • Sidebar 컴포넌트: 240px 고정 너비, 접기/펼치기, 로고, 네비게이션, 로그아웃
  • Utility Header: 48px 고정 높이, 브레드크럼, 알림, 사용자 정보
  • Page Header: 72px 고정 높이, 페이지 제목 + 도움말 텍스트
  • Search Container: 검색 영역 그리드 레이아웃, 검색 버튼
  • Table Header: 테이블 제목 + 건수 표시
  • Mobile Responsive: 사이드바 오버레이, 모바일 메뉴 제어
  • Pretendard Variable Font: 시스템 폰트 명시 (CDN)
