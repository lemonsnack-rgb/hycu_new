# 논문 심사 기능 프로세스 정의 (목업 기준)

- 작성일: 2026-10-08
- 기준: 현재 배포 목업 https://hycu-new.vercel.app (커밋 c2e4f54 이후), 기능정의서 v2.6
- 범위: 신청 · 신청 철회 · 제출 · 제출 수정 · 제출취소 · 심사(평가 · 판정) · 재심사(조건부합격 보완 / 불합격 후 재신청)
- 정의 방법(MECE)
  1. **단위**를 하나로 정함 → 2. **상태**를 겹치지 않게 나눔 → 3. **기능**을 주체별로 빠짐없이 나열 → 4. **상태 × 기능** 표로 모든 경우의 허용·차단을 정함 → 5. 재심사는 별도 기능이 아니라 위 기능의 **경로**로 정의

---

## 1. 단위: 심사 건

- **심사 건 = 학생 1명 + 기본단계 1개** (논문작성계획서 / 예비심사 / 본심사)
- 한 심사 건 안에서 제출·심사할 때마다 **차수**가 1씩 늘어남 (1차, 2차 …). 조건부합격 보완이든 불합격 후 재신청이든 같음
- 목록은 심사 건마다 1행(최신 차수). 상세 화면에 '1차 제출', '2차 제출'…(학생) / '1차 심사', '2차 심사'…(교수) 순서로 전부 표시
- 이전 기본단계 결과는 다른 심사 건이므로 영향 없음

## 2. 상태 정의

### 2-1. 화면에 표시되는 상태값 (기존 값만 사용)

| 구분 | 값 | 표시 위치 |
|---|---|---|
| 신청상태 | 미신청 / 신청완료 | 학생 논문신청 목록 |
| 제출상태 | 미제출 / 제출완료 | 학생 학위논문제출 목록 (최신 차수) |
| 심사결과 | - / 합격 / 조건부합격 / 불합격 | 학생 학위논문제출 목록·상세, 교수·관리자 학위논문심사 |
| 평가 상태 | 위원: [임시저장](반복 가능) → [제출](수정 불가) / 위원장 현황표: 미제출 위원 '대기', 제출 위원은 점수 | 교수 심사 상세 |

### 2-2. 심사 건 상태 (S0~S7) — 서로 겹치지 않고, 모든 경우를 포함

| 상태 | 신청상태 | 최신 차수 | 판별 조건 |
|---|---|---|---|
| **S0** 신청 전 | 미신청 | 없음 | 이 단계 신청 이력 없음 (또는 철회해서 이력 없음) |
| **S1** 제출 대기 | 신청완료 | 미제출 | 신청함, 이번 차수 미제출, 같은 신청 안에 결과 난 차수 없음 |
| **S2** 심사 대기 | 신청완료 | 제출완료 · 결과 - | 평가를 제출한 심사위원 0명 |
| **S3** 심사 중 | 신청완료 | 제출완료 · 결과 - | 평가를 제출한 심사위원 1명 이상 |
| **S4** 합격 | 신청완료 | 합격 | 단계 완료 (종료 상태) |
| **S5** 보완 제출 대기 | 신청완료 | 이전 차수 조건부합격 → 다음 차수 미제출 | 같은 신청 안에서 다음 차수가 생성됨 |
| **S6** 불합격 (같은 학기) | 미신청 | 불합격 | 불합격 처리된 학기 = 현재 학기 |
| **S7** 불합격 (다음 학기 이후) | 미신청 | 불합격 | 현재 학기가 불합격 처리된 학기 이후 |

- 보완 제출 후는 S2·S3과 같은 상태로 진행하되 "같은 신청 안에 결과가 확정된 차수가 있음" 표시를 가짐 → 이후 표에서 **S2′ / S3′** 로 구분
- '심사 진행 중' 판단: 심사위원 1명 이상 평가 **제출**(임시저장 제외, 질의 Q-04)

## 5. 재심사 경로 (위 기능의 조합)

| 경로 | 순서 | 신청 필요 | 다시 심사하는 위원 |
|---|---|---|---|
| **조건부합격 보완** | S3 → F11 조건부합격 → S5 → F4 보완 제출 → S2′ → F10 → F11 | 없음 (같은 신청) | 위원장이 지정한 위원(전체 또는 1명) 평가 후 위원장 판정 |
| **불합격 후 재신청** | S3 → F11 불합격 → S6 → (다음 학기) S7 → F1 → S1 → F4 → S2 → F10 → F11 | 필요 (다음 학기 이후) | 관리자가 기존 화면에서 배정(F8) |

- 두 경로 모두 같은 심사 건의 다음 차수로 표시되고, 이전 차수 기록(파일·평가·판정·총평)은 보존
- 판정 결과에 따른 분기는 1차 심사와 같음 (반복 횟수 제한 기능 없음)

## 7. 목업으로 확인하지 않는 것 (정의 범위 밖)

- 화면 간 데이터 연동 (교수 판정 → 학생 화면 반영): 학생 화면은 시연 바(①~④)로 상태를 재현
- 같은 학기 불합격(S6) 차단: 시연 시나리오 없음 (자동 테스트로 확인)
- DB View 값 변경(CM-05), 지도교수 변경 반영, 철회 시 심사일정 처리: 질의 Q-05~Q-08, Q-21, Q-22
- 한 기본단계에 세부단계가 여러 개인 경우의 부분 보존: 목업은 기본단계당 세부단계 1개
