# 논문 심사 기능 프로세스 정의 (목업 기준)

- 작성일: 2026-10-08 / 갱신: 2026-10-08 (신청 철회·제출취소 분리, 심사중·결과 확정 차수 수정 불가, 불합격 후 신청 유지 원칙, 문서 중복 정리)
- 기준: 현재 배포 목업 https://hycu-new.vercel.app , 기능정의서 v3.0
- **이 문서가 프로세스의 단일 기준**입니다. 같은 사실은 한 곳에만 씁니다 — 조건은 §2 규칙, 문구·기간·화면 동작은 §4 기능, 허용·차단은 §5 표
- **핵심 목표**: 통과(판정)된 심사 내역은 남기고, 철회·재심은 **특정 단계(차수)에 대해서만** 할 수 있게 한다

---

## 1. 단위: 심사 건과 차수

- **심사 건 = 학생 1명 + 기본단계 1개** (논문작성계획서 / 예비심사 / 본심사)
- **차수 = 심사 건 안의 제출·심사 1회** (1차, 2차 …). 조건부합격 보완이든 불합격 후 재심사든 같음
- 목록은 심사 건마다 1행(최신 차수). 상세 화면에 '1차 제출', '2차 제출'…(학생) / '1차 심사', '2차 심사'…(교수) 순서로 전부 표시
- 이전 기본단계 결과는 다른 심사 건이므로 영향 없음
- **단위 원칙**: 신청·신청 철회 = **기본단계** 단위 / 제출·제출취소·심사·판정(불합격 포함) = **세부단계(차수)** 단위. 세부단계의 취소·불합격은 신청에 영향을 주지 않음 (기본단계 신청을 리셋하면 이미 통과한 세부단계 이력까지 초기화되므로)

## 2. 규칙 (조건만)

| 규칙 | 조건 | 적용 기능 |
|---|---|---|
| R1 심사중 | 심사위원 평가가 1건 이상 저장(**임시저장 포함**)된 차수 | R3·R4 |
| R2 범위 분리 | 신청 철회 = 신청과 그 신청의 제출 삭제 / 제출취소 = 해당 차수 제출만 삭제 (신청·이전 차수 유지) | F3, F7 |
| R3 신청 잠금 | 같은 신청 안에 R1 상태이거나 판정 결과가 있는 차수가 있으면 신청 철회 불가 | F3 |
| R4 차수 잠금 | 해당 차수가 R1 상태이거나 판정 결과가 있으면 그 차수의 제출취소·수정 불가 (이전 차수 결과와 무관) | F6, F7 |
| R5 불합격 학기 | 불합격 처리된 학기에는 같은 단계를 다시 진행 불가 (1안: 제출 차단 / 2안: 신청 차단) | F1, F4 |
| R6 신청 유지 | 불합격 후에도 신청은 유지하고 해당 세부단계만 다음 차수로 다시 제출 (1안). 행정상 재신청이 반드시 필요한 경우만 대안으로 신청만 리셋 (2안, 기능정의서 Q-25) | §6 |

## 3. 상태

### 3-1. 화면 상태값 (기존 값만 사용)

| 구분 | 값 | 표시 위치 |
|---|---|---|
| 신청상태 | 미신청 / 신청완료 | 학생 논문신청 목록 |
| 제출상태 | 미제출 / 제출완료 | 학생 학위논문제출 목록 (최신 차수) |
| 심사결과 | - / 합격 / 조건부합격 / 불합격 | 학생 학위논문제출, 교수·관리자 학위논문심사 |
| 평가 상태 | 위원: [임시저장](반복 가능) → [제출](수정 불가) / 위원장 현황표: 미제출 위원 '대기', 제출 위원은 점수 | 교수 심사 상세 |

### 3-2. 심사 건 상태 (S0~S7) — 서로 겹치지 않고, 모든 경우를 포함

| 상태 | 판별 조건 | 신청상태 (1안 / 2안) | 학위논문제출 최신 행 |
|---|---|---|---|
| **S0** 신청 전 | 신청 이력 없음 (또는 신청 철회로 삭제) | 미신청 | 없음 |
| **S1** 제출 대기 | 신청함, 이번 차수 미제출, 같은 신청 안에 판정된 차수 없음 | 신청완료 | N차 제출 · 미제출 |
| **S2** 심사 대기 | 이번 차수 제출, R1 아님 | 신청완료 | N차 제출 · 제출완료 · 결과 - |
| **S3** 심사 중 | 이번 차수 R1, 결과 전 | 신청완료 | N차 제출 · 제출완료 · 결과 - |
| **S4** 합격 | 결과 합격 (종료) | 신청완료 | 합격 |
| **S5** 보완 제출 대기 | 이전 차수 조건부합격, 다음 차수 미제출 | 신청완료 | N+1차 제출 · 미제출 |
| **S6** 불합격 · 같은 학기 | 불합격 처리된 학기 = 현재 학기 | 신청완료 / 미신청 | 1안: N+1차 · 미제출 / 2안: 불합격 |
| **S7** 불합격 · 다음 학기 이후 | 현재 학기 > 불합격 처리된 학기 | 신청완료 / 미신청 | 1안: N+1차 · 미제출 / 2안: 불합격 |

- **S2′ / S3′** = 같은 신청 안에 판정된 이전 차수가 있는 S2 / S3 (조건부합격 보완 제출 후, 1안의 불합격 후 다음 차수 제출 후)
- 2안에서 다시 신청하면 새 신청이므로 S1·S2·S3과 같음
