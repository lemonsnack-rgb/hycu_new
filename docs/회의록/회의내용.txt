# 관리자 화면

1) 논문지도학생현황: 학생의 현재 단계, 다가오는 단계 조회 가능하도록 해야 함, 학생의 상세 정보 조회하는 화면(모달 팝업 등) 추가해야 함 

현재는 수동으로 모든 학생의 단계를 다음 단계로 이동시키고 있음. 자동으로 옮기도록 수정해야 함. 자도의 기준은 각 단계별 심사 - 평가임 (각 단계에 평가표를 적용하고, 평가 완료 - 승인 완료 시 단계 이동)

평가와 승인은 각 심사위원이 함. 현재는 지도교수가 심사위원장을 못하도록 되어 있는데, 현실 세계에서는 지도교수 혼자 심사완료까지 하는 경우가 많으므로 이를 고려해야 함.

위 사항에 따라 심사유형이 심사위원단이 구성되는 경우, 지도교수가 단독으로 하는 경우를 구분해야 함. 중요한 것은 단계 이동을 자동화하는 것.명확한 자동화 트리거 포인트가 필요하다는 것

2) 지도단계유형관리: 제출요건의 문서제출필요, 발표필요가 의미 없음. 삭제하거나 해야 함  

3) 지도단계 등록: 평가표 없는 항목은 없음

4) 심사평가기준등록: 평가 유형에 별도 점수 부여하지 않고, 단계 진행을 위해 서술형 평가만하는 평가표 유형이 필요함 



# 학생용화면
1) 논문지도활동: 학생이 PDF 파일을 올릴 때에도 영역 지정, 코멘트 남길 수 있어야 함. 의도는 이전 버전에서 교수가 작성한 피드백이 정상 적용되었는지를 새로운 버전에 표시하기 위함임. 
2) 논문신청: 현재는 심사 대상인 단계에 대해서만 문서를 제출할 수 있도록 되어 있음. 심사위원단이 구성되는 평가와 그렇지 않은 평가를 나누고, 학생이 논문 작성단계에서 만들어내는 모든 문서를 올릴 수 있도록 해야 함
3) 대시보드 및 기타: 학생이 본인에게 적용된 논문지도단계를 조회할 수 있어야함 (다이어그램 방식)


# 교수용화면
1) 학위논문심사: 실제 심사를 요하는 것만 따로 보는 화면, 학생이 올린 모든 문서를 조회하는 목록을 구분해서 볼수 있어야 함
2) 학생별 상세정보: (관리자용에도 필요) 학생 상세정보(학적정보 등)와 그 학생에게 적용된 논문지도단계 다이어그램 또는 비주얼영역, 해당 학생이 올린 각 단계별 산출물 목록을 조회하는 화면이 필요함
