## 1. 관리자 화면

### 1.1 논문지도학생현황
- **학생 상세 정보 조회 화면 추가**
  - 학생의 현재 단계, 다가오는 단계 조회 기능
  - 학생 상세 정보 조회 화면(모달 팝업 등) 추가 필요
  - 학생별 학적정보, 논문지도단계 다이어그램, 각 단계별 산출물 목록 조회 필요

### 1.2 단계 자동 이동
- **현황**: 현재 수동으로 모든 학생의 단계를 이동
- **요구사항**: 자동화 필요
  - 각 단계별 심사-평가 완료-승인 완료 시 단계 자동 이동

### 1.3 심사 유형 구분
- **심사위원단 구성 vs 지도교수 단독 심사** 구분 필요
- 심사 유형에 따른 프로세스 차별화

### 1.4 지도단계유형관리
- **제출요건** 관련
  - 문서제출필요, 발표필요 항목 삭제 또는 수정 검토

### 1.5 지도단계 등록
- 평가표 없는 항목 처리 방안 필요

### 1.6 심사평가기준등록
- **서술형 평가 유형 추가**
  - 점수 부여 없이 서술형 평가만 하는 평가표 유형 필요

## 2. 학생용 화면

### 2.1 논문지도활동 - PDF 피드백 기능

#### 2.1.1 학생의 PDF 업로드 및 피드백 수정
- **학생의 영역 지정 및 코멘트 기능**
  - 교수 피드백 적용 여부 표시
  - 이전 버전의 교수 피드백에 대한 학생의 수정 사항 반영 표시 필요

#### 2.1.2 첨삭 권한 부여
- **핵심 요구사항**: 학생도 첨삭 탭에서 댓글을 달 수 있도록 권한 부여
  - 교수님 피드백(이전 버전)을 불러와서 학생이 "이 부분을 이렇게 수정했습니다" 표시
  - 신규 버전 PDF에 구 버전의 피드백 번호를 연결하여 댓글 작성
  - 교수님이 요청한 사항을 학생이 어떻게 반영했는지 명시

#### 2.1.3 피드백 삭제 기능
- **학생의 제출 철회 기능**
  - 피드백 대기 상태(교수님이 아직 열람하지 않은 상태)에서만 삭제 가능
  - 교수님이 열람(열람 카운트 1 이상)한 경우 삭제 불가
  - 열람 즉시 "피드백 중" 상태로 자동 전환
  - 삭제 버튼은 상세 화면 내부에 배치 (목록이 아닌 뷰어 내부)

#### 2.1.4 신구 대조 및 버전 관리
- **문제점**: PDF 버전 간 피드백 위치 매칭 불가
- **대안 1** (최우선): 학생이 첨삭 탭에서 이전 피드백을 선택하여 댓글 작성
- **대안 2**: PDF 다운로드 시 첨삭 번호 포함 (기술 검토 필요)
- **대안 3**: 이전 버전을 새 창으로 열어 두 문서 비교 가능하도록 UI 제공

### 2.2 논문신청
- **심사위원단 구성 평가와 그렇지 않은 평가 구분**
  - 심사 유형에 따른 신청 프로세스 차별화
- **모든 문서 업로드 가능하도록 변경**
  - 제한 없이 필요한 문서 첨부 가능

### 2.3 대시보드
- **학생에게 적용된 논문지도단계 조회**
  - 다이어그램 방식으로 시각화
  - 현재 단계 및 전체 진행 상황 한눈에 파악

## 3. 교수용 화면

### 3.1 실시간 지도 예약 관리

#### 3.1.1 지도 가능 시간 등록
- **디폴트 시간 설정 없음**
  - 교수님이 직접 등록해야 학생 신청 가능
  - 시스템 진입 시 "시간 설정 필요" 안내 팝업 표시

- **UI 개선 필요**
  - 캘린더 뷰와 목록 뷰 병행 검토
  - 월별 일정 확인 가능하도록 개선
  - 반복 일정 등록 UI 개선 (특정 날짜 1회/반복 일정 구분 명확화)

#### 3.1.2 예약 상태 관리
- **상태 구분**: 대기, 확정, 완료, 거절
- **거절 사유 입력 및 조회 기능**
- **탭으로 구분**: 대기/진행 중 vs 완료
- **교수의 일정 삭제 기능**

#### 3.1.3 예약 완료 처리
- **완료 처리 자동화**
  - 미팅 일정 날짜 경과 시 자동 완료 처리
  - 명시적 완료 버튼 제거 검토

#### 3.1.4 참여 학생 정보 표시
- **1:N 미팅 고려**
  - "김철수 외 3명" 형식으로 표시
  - 학생 필터 기능 (이름 검색)

#### 3.1.5 줌 미팅 정보
- 온라인 미팅 선택 시 Zoom API 자동 연동
- 미팅 URL, ID, 비밀번호 자동 생성
- 생성 완료 시 "학생들에게 공유되었습니다" 알림 메시지

### 3.2 논문지도활동 - 피드백 관리

#### 3.2.1 피드백 목록 화면
- **디폴트 필터**: 피드백 상태 = "대기"
  - 교수님이 처리해야 할 투두 리스트 우선 표시
- **탭 구분**: 대기/진행 중 vs 완료

#### 3.2.2 피드백 상태 관리
- **상태**: 대기 → 진행 중 → 완료
- **진행 중 전환 조건**: 교수님이 논문 열람 시 자동 전환 (열람 카운트 기반)
- **완료 전환 조건**: 교수님이 "피드백 완료" 버튼 클릭 시
  - 학생에게 알림 발송

#### 3.2.3 전체 평가 기능
- **교수님당 1회 제한**
  - 영역 지정 없이 전체 평가 입력
  - 수정 가능하지만 여러 건 등록 불가
- **입력창 위치**: 탭 내 최상단 고정
- **정렬 순서**: 주지도교수 → 공동지도교수 (등록순 또는 가나다순)

#### 3.2.4 첨삭 UI 개선
- **탭 구조**: 전체 평가 / 첨삭
- **첨삭 탭 내용**:
  - 전체 평가 입력란 (상단 고정)
  - 페이지별 첨삭 목록

#### 3.2.5 글씨 가독성
- 전반적으로 폰트 사이즈 및 색상 개선 필요
- 다른 시스템 대비 가독성 저하 피드백

### 3.3 학위논문심사
- **실제 심사 대상과 학생이 올린 모든 문서 목록 구분하여 조회**
  - 심사 대상 문서와 참고 문서 명확히 구분

### 3.4 학생별 상세정보
- **학생 상세정보 조회 화면 필요**
  - 학적정보 (학번, 학과, 학위과정 등)
  - 논문지도단계 다이어그램
  - 각 단계별 산출물 목록 조회

### 3.5 논문지도 자료실

#### 3.5.1 자료 공유 기능
- 교수 → 학생 자료 제공
- 학생 → 교수 자료 제공
- 학생 선택 옵션: 전체 학생 / 개별 학생 선택

#### 3.5.2 학생 선택 UI
- **필터 기능**: 학과, 학위과정, 지도단계
- **표시 정보**: 이름, 학번, 학과, 학위과정, 현재 지도단계
- **UI 개선**: 선택된 학생을 별도 영역에 표시 또는 팝업 활용

#### 3.5.3 댓글 기능
- 학생도 댓글 작성 가능
- 대댓글 기능은 유지하되 "질문은 댓글로 작성하세요" 안내 문구 추가

#### 3.5.4 게시글 기능
- 고정글 기능
- 중요 글 표시
- 학위과정별 필터 (전체/석사/박사)
- 조회수, 댓글수 표시
- 이전글/다음글 네비게이션

#### 3.5.5 파일 업로드
- 파일 개수: 10개
- 파일당 용량: 20MB (ERP와 동일)
- 총 용량: 200MB

## 4. 공통 사항

### 4.1 UI/UX 개선

#### 4.1.1 조회 조건
- **학생 정보 간소화**
  - 계열, 대학 등 중복 정보 제거
  - 학과, 학위과정, 학년, 학기 위주로 정리
  - LMS 수강생 목록 수준으로 간소화

#### 4.1.2 목록 및 테이블
- 컬럼 정보 최적화
- 검색 및 필터 기능 강화
- 정렬 기능 (최신순, 가나다순 등)
- 페이징 옵션 (100개씩 보기 등)

#### 4.1.3 탭 및 상태 표시
- 탭 UI 명확화
- 상태별 색상 구분 (뱃지, 아이콘 등)
- 디폴트 탭/필터 설정

### 4.2 알림 시스템
- 피드백 완료 시 학생에게 알림
- 예약 확정/거절 시 알림
- 자료 공유 시 알림

### 4.3 권한 관리
- 교수 권한: 피드백, 평가, 자료 공유, 예약 관리
- 학생 권한: 제출, 댓글, 예약 신청
- 관리자 권한: 단계 관리, 전체 데이터 조회

### 4.4 데이터 관리
- 삭제 조건 명확화 (열람 여부, 상태 등)
- 버전 관리 (이력 보관)
- 열람 카운트 추적

## 6. 우선순위 정리

### 최우선 (P0)
1. **학생 첨삭 권한 부여** - 논문지도활동의 핵심 기능
2. **피드백 상태 관리** - 대기/진행중/완료 구분 및 삭제 조건
3. **실시간 예약 UI 개선** - 교수/학생 모두 사용 편의성 개선

4. 단계 자동 이동 기능
5. 학생 상세정보 조회 화면
6. 전체 평가 1회 제한 및 UI 개선
7. 조회 조건 간소화

### 중우선 (P2)
8. 자료실 학생 선택 UI 개선
9. 신구 대조 기능 (PDF 다운로드 또는 새 창)
10. 글씨 가독성 개선

### 저우선 (P3)
11. 반복 일정 등록 옵션 추가
12. 캘린더 뷰 개선
13. 기타 UI 세부 개선사항

## 부록: 주요 용어 정리

- **지도단계**: 연구계획서, 예비심사, 본심사, 최종논문 등
- **심사 유형**: 심사위원단 구성 / 지도교수 단독 심사
- **피드백 상태**: 대기(학생 제출 후 교수 미열람), 진행중(교수 열람), 완료(피드백 완료 버튼 클릭)
- **열람 카운트**: 교수가 학생 제출물을 열람한 횟수 (삭제 가능 여부 판단 기준)
- **주지도교수 / 공동지도교수**: 논문지도 역할 구분
