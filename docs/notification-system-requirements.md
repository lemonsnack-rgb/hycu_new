# 알림 시스템 요구사항 명세서

## 1. 개요

본 문서는 논문 지도 시스템의 사용자 액션 기반 알림 시스템에 대한 요구사항을 정의합니다.

---

## 2. 알림 대상자 분류

| 사용자 유형 | 역할 | 알림 수신 조건 |
|------------|------|---------------|
| 학생 | 논문 작성자 | 지도교수의 피드백, 심사 결과, 제출 승인/반려 |
| 교수 | 논문 지도교수 | 학생의 제출 요청, 피드백 요청, 계획 등록 |
| 관리자 | 시스템 관리 | 제출 현황, 심사 일정, 시스템 이벤트 |

---

- `담당 교수님이 [학기명] 학기별 지도 계획을 반려했습니다. 사유: [반려사유]`

- `학술지 논문 심사 결과: 게재 승인`

## 5. 알림 발송 채널

### 5.1 인앱 알림 (In-App Notification)
- 모든 알림의 기본 발송 채널
- 시스템 내 알림 센터에 표시
- 읽음/안읽음 상태 관리
- 알림 클릭 시 해당 화면으로 이동

### 5.2 이메일 알림
- 우선순위 "높음" 알림에 한해 이메일 발송
- 사용자 설정에서 이메일 알림 수신 여부 선택 가능
- 배치 처리: 10분마다 수집하여 발송

### 5.3 SMS 알림 (선택 사항)
- 심사 일정 알림 등 특정 알림만 SMS 발송
- 사용자 설정에서 SMS 알림 수신 여부 선택 가능

### 5.4 브라우저 푸시 알림 (선택 사항)
- 사용자가 브라우저 푸시 알림 권한 허용 시 발송
- 실시간 알림 필요한 경우 사용

## 6. 알림 데이터 구조

### 6.1 알림 객체 스키마

```javascript
{
  id: string,                    // 알림 고유 ID
  notificationCode: string,      // 알림 코드 (예: THESIS_SUBMITTED)
  title: string,                 // 알림 제목

  senderName: string,            // 발신자 이름
  receiverType: string,          // 수신 대상 유형 (student/professor/admin)
  receiverId: string,            // 수신자 ID
  priority: string,              // 우선순위 (high/medium/low)
  category: string,              // 알림 카테고리 (guidance/submission/review/etc)
  relatedEntity: {               // 관련 엔티티 정보
    type: string,                // 엔티티 타입 (thesis/guidance/schedule/etc)
    id: string,                  // 엔티티 ID
    title: string                // 엔티티 제목
  },
  actionUrl: string,             // 알림 클릭 시 이동할 URL

  createdAt: timestamp,          // 생성 시각
  readAt: timestamp,             // 읽은 시각
  expiresAt: timestamp           // 만료 시각 (선택 사항)
}
```

## 7. 알림 생성 규칙

### 7.1 중복 알림 방지
- 동일한 이벤트에 대해 10분 이내 중복 알림 발송 금지
- 예: 같은 학생이 같은 논문 지도 요청을 10분 내 수정 시, 첫 번째 알림만 발송

### 7.2 알림 그룹화
- 같은 카테고리의 알림이 5개 이상 발생 시 그룹화
- 예: "3개의 새로운 논문 지도 요청이 있습니다."

### 7.3 알림 만료
- 읽지 않은 알림은 30일 후 자동 만료
- 만료된 알림은 알림 목록에서 자동 삭제

### 7.4 알림 우선순위 처리
- 높음: 즉시 발송
- 보통: 5분 배치 처리
- 낮음: 1시간 배치 처리

## 11. 테스트 시나리오

### 11.1 학생 → 교수 알림 테스트
1. 학생이 논문 지도 요청 등록
2. 교수 알림 센터에 즉시 알림 표시 확인
3. 교수가 알림 클릭 시 해당 지도 요청 화면 이동 확인

### 11.2 교수 → 학생 알림 테스트
1. 교수가 논문 지도 피드백 등록
2. 학생 알림 센터에 즉시 알림 표시 확인
3. 학생이 알림 클릭 시 해당 피드백 화면 이동 확인

### 11.3 관리자 → 학생/교수 알림 테스트
1. 관리자가 심사 일정 등록
2. 학생 및 심사위원 알림 센터에 알림 표시 확인
3. 알림 클릭 시 심사 일정 화면 이동 확인

### 11.4 시스템 자동 알림 테스트
1. 심사 3일 전 자동 알림 발송 확인
2. 제출 마감 7일/3일/1일 전 자동 알림 발송 확인
3. 실시간 지도 1시간 전 자동 알림 발송 확인
