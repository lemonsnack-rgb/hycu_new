## 1. 심사 판정 체계 ★ 1순위

### 1-1. '조건부합격'과 '불합격'의 구분 기준

현재 목업에서 위원장 최종 판정은 **합격 / 조건부합격 / 불합격** 세 가지입니다. 두 판정의 차이는 판정 이후의 절차뿐입니다.
- **조건부합격:** 같은 학기 안에 심사 신청 없이 보완 자료만 다시 제출하고 재심을 받습니다.
- **불합격:** 다음 학기에 심사 신청부터 다시 진행합니다.

**어떤 경우에 어느 판정을 고르는지는 정해져 있지 않습니다.** 점수로 자동 산출되는 결과도 합격/불합격 두 가지뿐이라, 지금은 위원장이 판단하는 것 말고는 구분할 기준이 없습니다. 아래 표를 채워 주시기 바랍니다.

| 항목 | 조건부합격 | 불합격 |
|---|---|---|
| 어떤 경우에 선택하는지 (예: 부분 보완 / 전면 수정, 점수 구간) | | |
| 결과를 합격으로 보는지 불합격으로 보는지 | | 불합격 |
| 다음 심사단계(예: 예비심사 → 본심사)로 진행할 수 있는 시점 | 목업: 재심에서 합격한 후 | 불가 |
| 학적·DB View에 남는 결과값 | | |

### 1-2. 판정 명칭

- **요구사항정의서:** 운영 중인 시스템은 **'불합격(재심사)'**(선택한 심사위원만 재심)와 **'불합격(영구)'**를 쓴다고 되어 있습니다.
- **목업:** 같은 기능을 **'조건부합격'**과 **'불합격'**으로 표기했습니다.

'조건부합격'은 보통 "보완을 조건으로 한 합격"으로 읽힙니다. 그래서 다시 심사를 받아야 하는 판정의 이름으로 쓰면 혼동이 생길 수 있습니다. 아래 중 하나를 골라 주세요.

- (가) 합격 / 조건부합격 / 불합격 — 현재 목업
- (나) 합격 / 불합격(재심사) / 불합격(재신청) — 운영 시스템 명칭 계열 **(무하유 권장)**
- (다) 기타: ________

또한 '불합격(영구)'라는 명칭은 없애고 모든 불합격을 재진행 가능한 것으로 봐도 되는지 확인 부탁드립니다.

### 1-3. 불합격 후 재신청 시점 (요구사항 문구 간 차이)

- **요구사항정의서(JXLB-1):** "심사 신청 기간 내 신청 가능 (동일 학기 또는 이후 학기 모두 가능)"
- **목업:** **다음 학기**에만 신청할 수 있게 했습니다.
  - 같은 학기 안에 다시 보는 심사는 조건부합격(재심)으로 처리했습니다.

같은 학기 재신청도 허용해야 하는지 확인 부탁드립니다.

## 3. 불합격 후 재심사

| # | 확인 사항 | 현재 목업 |
|---|---|---|
| 3-1 | '재심사 진행' 상태가 붙는 시점과 명칭 | 불합격이 확정되면 **'재심사 대상'**, 다시 신청하면 **'신청완료'**, 학생 대시보드는 **'재심사 진행'**. 요구서의 '재심사 진행'을 어느 시점에 표시할지 확인 필요 |
| 3-2 | 학생에게 보여줄 이전 차수 기록의 범위 | 제출 파일, 결과, **심사위원장 총평**. 위원별 점수와 평가표는 보여주지 않음 |

| 3-4 | 재신청 횟수를 "행정으로 제어"하려면 관리자가 특정 학생의 재신청을 막는 기능이 필요한지 | 기능 없음 (횟수 제한 없음) |
| 3-5 | 불합격자만을 위한 별도 신청기간이 있는지, 일반 신청기간과 같은지 | 일반 신청기간과 같음 |

## 4. 심사신청 철회

### 4-1. 철회 단위 ★ 1순위

**요구사항정의서(JXLB-2)의 예시:** "본심사 2차 신청·자료제출 상태에서 철회하면 본심사 1차 결과는 유지하고, 2차 제출 버튼이 다시 활성화되며, 심사위원 배정 내역은 삭제"
- 이 예시는 **세부단계(제출 건) 단위**로 취소하는 것처럼 읽힙니다.

**목업은 두 기능을 나눴습니다.**
- **신청 철회:** 기본단계의 **심사신청 자체**를 취소합니다. 결과가 나오지 않은 제출 자료는 삭제하고, 결과가 확정된 기록은 보존합니다.
- **제출취소:** 신청은 그대로 두고 **제출한 자료만** 삭제합니다. 다시 제출할 수 있습니다.

이렇게 나눠도 되는지 확인 부탁드립니다.

### 4-2. 기타

| # | 확인 사항 | 현재 목업 |
|---|---|---|
| 4-2 | "심사 진행 중"의 기준: 심사위원이 평가를 **최종 제출**했을 때만인지, **임시저장**도 포함하는지 | 평가를 저장한 위원이 1명 이상이면 진행 중으로 봄 |
| 4-3 | 철회기간을 신청기간과 따로 운영하는지 | 별도 기간으로 표시 |
| 4-4 | 관리자가 학생 대신 철회할 수 있어야 하는지 | 학생만 가능 |
